Arrow’sImpossibility Theorem

Kenneth Arrow (1951): with 3 or more candidates, no ranking-based voting rule can satisfy all five conditions in every election.

01
Unrestricted domainevery ballot counts
Any honest ranking is allowed, and the rule must work for every mix of ballots.
02
Transitivityno going in circles
If the group puts Aarav above Meera and Meera above Kabir, Aarav must be above Kabir.
03
Unanimityif everyone agrees, the result agrees
If every student prefers Aarav to Meera, so must the result.
04
Non-dictatorshipnobody is the boss
The rule can’t just copy one student’s ranking.
05
Independenceof irrelevant alternatives
Moving Kabir shouldn’t change whether Aarav or Meera is ahead. With Borda points it does.
No perfect voting system, only trade-offs
